# پارچه‌سرا — فروشگاه جامع پارچه (PHP + MySQL برای IIS)

یک وب‌اپلیکیشن کامل فروشگاهی برای انواع پارچه با پنل مدیریت مخفی (فقط با لینک مستقیم)، دسته‌بندی درختی، سفارش‌گیری، فاکتور، انبار، پیام‌رسان داخلی و فروش چند‌فروشنده‌ای.

## امکانات

### طراحی و ظاهر
- تمام آیکون‌های سایت و پنل از **یک آیکون‌پک یکدست (Lucide)** به‌صورت SVG درون‌خطی — بدون ایموجی، بدون درخواست خارجی
- **فونت‌های فارسی self-hosted** (وزیرمتن، شبنم، ساحل، صمیم، پرستو، گندم، طنها) — بدون نیاز به اینترنت
- **تغییر فونت و اندازه فونت کل سایت از پنل مدیریت** (تنظیمات → فونت کل سایت)
- راست‌چین کامل، اعداد و تاریخ شمسی فارسی، ریسپانسیو

### سایت عمومی (مشتریان)
- صفحه اصلی با بنر، دسته‌بندی‌ها، محصولات پیشنهادی و جدیدترین‌ها
- دسته‌بندی درختی پارچه‌ها (۴ دسته اصلی + ۱۵ زیرشاخه، قابل گسترش تا بی‌نهایت سطح)
- فیلتر قیمت، فقط موجودها، مرتب‌سازی (جدیدترین/پرفروش/ارزان/گران) + صفحه‌بندی
- صفحه محصول با گالری، مشخصات (جنس، عرض، رنگ، طرح، مبدا)، سفارش متراژ و نظرات با تایید مدیر
- جستجو در نام/توضیحات/جنس/رنگ/طرح
- سبد خرید با کنترل موجودی لحظه‌ای
- تسویه حساب با کد تخفیف (درصدی/مبلغی با حداقل مبلغ و سقف استفاده)
- ثبت سفارش مهمان یا عضو + کد پیگیری (`ORD-xxxxxx`) و صفحه رهگیری با تایم‌لاین وضعیت
- فاکتور فروش چاپی (`INV-xxxxxx`) به تفکیک فروشنده + تاریخ شمسی
- حساب کاربری: پیشخوان، سفارش‌ها، جزئیات سفارش، فاکتورها، پیام‌رسان داخلی، پروفایل

### پنل مدیریت (فقط با لینک مستقیم — هیچ دکمه/لینکی در سایت ندارد)

## نصب روی IIS (ویندوز سرور) با MySQL

### ۱) پیش‌نیازها
1. **IIS** با نقش **CGI** (Server Manager → Add Roles → Web Server → Application Development → CGI)
2. **PHP 7.4+ (پیشنهادی 8.x)** نسخه Non-Thread-Safe برای IIS FastCGI — از windows.php.net دانلود کنید
   - در `php.ini` این‌ها فعال باشند: `pdo_mysql` ، `mbstring` ، `fileinfo` ، `gd` (اختیاری) و `extension_dir` درست باشد
3. **MySQL 5.7+ / 8.x** یا MariaDB
4. ماژول **URL Rewrite** لازم نیست؛ سایت با آدرس‌های مستقیم `.php` کار می‌کند

### ۲) قرار دادن فایل‌ها
کل محتویات پوشه `parche` را در ریشه سایت کپی کنید؛ مثلاً:
```
C:\inetpub\wwwroot\parche\
```

### ۳) دسترسی‌ها (Permission)
به این پوشه‌ها برای هویت **IIS_IUSRS** (یا APPPOOL identity) دسترسی **Modify** بدهید:
- `uploads\`  (تصاویر محصولات)
- `data\`     (فقط اگر SQLite می‌خواهید — برای MySQL لازم نیست)
- `app\`      (فقط هنگام نصب، برای ساخت config.php — بعد از نصب می‌توانید فقط-خواندنی کنید)

### ۴) نصب
مرورگر: `http://your-domain/install/`
1. نوع دیتابیس را **MySQL** بگذارید
2. هاست/پورت/نام دیتابیس/کاربر/رمز MySQL را وارد کنید (دیتابیس اگر نبود خودکار ساخته می‌شود)
3. ایمیل و رمز **مدیر** را تعیین کنید
4. تیک «داده‌های نمونه» را بزنید تا دسته‌بندی‌ها و محصولات دمو نصب شوند
5. در پایان آدرس پنل را یادداشت کنید

نصب‌کننده بعد از اتمام خودش را قفل می‌کند (`install/.locked`). برای نصب مجدد این فایل را حذف کنید.

### ۵) ورود به پنل
```
http://your-domain/panel/login.php
```
پنل هیچ لینکی در سایت ندارد و فقط با همین آدرس باز می‌شود. برای امنیت بیشتر می‌توانید پوشه `panel` را به نامی مخفی تغییر دهید (مثل `pnl-k3x9`)؛ همه لینک‌های داخل پنل نسبی هستند و پنل سالم کار می‌کند.

## ساختار پروژه
```
├── index.php / category.php / product.php / search.php    ← سایت عمومی
├── cart.php / checkout.php / order-success.php / track.php
├── invoice.php          ← فاکتور چاپی عمومی با کد
├── login.php / register.php / logout.php / account.php / about.php
├── panel/               ← پنل مدیریت/فروشنده (فقط لینک مستقیم)
├── install/             ← نصب‌کننده وب + نصب CLI (cli-install.php)
├── app/                 ← هسته (db، helpers، auth، cart، schema، icons) — با web.config مسدود است
├── inc/                 ← قالب هدر/فوتر سایت
├── uploads/             ← تصاویر محصولات و بنر (قابل نوشتن)
├── data/                ← دیتابیس SQLite فقط برای دمو
├── assets/              ← css/js + فونت‌های فارسی (assets/fonts)
└── web.config           ← تنظیمات IIS (default document + مسدودسازی app/data)
```

## اجرای دمو بدون IIS (اختیاری)
اگر PHP با pdo_mysql ندارید، برای تست سریع می‌توانید از SQLite استفاده کنید:
```bash
php install/cli-install.php     # نصب دمو روی data/parche.sqlite
php -S 0.0.0.0:8080             # اجرا در ریشه پروژه
```
برای تولید (Production) روی IIS حتماً **MySQL** را در نصب‌کننده انتخاب کنید.

## فاز بعدی (آماده‌سازی شده)
- **بالانس دسته‌بندی‌ها**: فیلد `balance` روی جدول categories هم‌اکنون در پنل قابل ویرایش است و می‌تواند وزن نمایش/اولویت فروش هوشمند را تعیین کند
- **طرح فروش هوشمند**: زیرساخت (بالانس دسته‌ها، پرچم پیشنهادی، تخفیف‌ها و آمار فروش در داشبورد) فراهم است
- درگاه پرداخت آنلاین (زرین‌پال و ...): ساختار سفارش/فاکتور آماده اتصال است

## نکات امنیتی پیاده‌سازی‌شده
- PDO + Prepared Statements در همه کوئری‌ها
- توکن CSRF روی تمام فرم‌های POST
- `password_hash` برای رمزها + خروجی‌ها با `htmlspecialchars`
- مسدودسازی `app` و `data` در `web.config` (requestFiltering)
- `noindex` روی پنل + عدم وجود هرگونه لینک به آن در سایت
